Desenvolva um programa em Java que utilize uma estrutura de repetição for para
percorrer todos os números inteiros de 0 até 100.
Para cada número, o programa deverá apresentar:
• o valor atual;
• o quadrado desse valor.
Cada resultado deverá ser apresentado em uma linha diferente.
Exemplo de saída
0 - 0
1 - 1
2 - 4
3 - 9
4 - 16
...
100 - 10000
O quadrado de um número deverá ser calculado pela multiplicação do valor por
ele mesmo
