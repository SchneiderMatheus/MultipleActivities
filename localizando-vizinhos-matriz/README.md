Desenvolva um programa em Java que leia dois números inteiros M e N e, em
seguida, gere uma matriz de M linhas por N colunas contendo números inteiros
aleatórios entre 1 e 100.
Após preencher a matriz, leia um número inteiro X, que pertença à matriz.
Para cada ocorrência de X, o programa deverá apresentar, quando existirem, os
valores localizados:
• à esquerda;
• acima;
• à direita;
• abaixo.
Caso alguma dessas posições não exista (por exemplo, quando X estiver em uma
borda da matriz), ela não deverá ser apresentada.
Dica: utilize a biblioteca <random> para gerar os números aleatórios.
